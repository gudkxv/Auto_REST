# **AUTO_REST - это?** :shipit:
<hr>
Auto_Rest - проект-игрушка, где я просто пробовал построить REST-сервис. Якобы есть какой-то сервис, ремонтирующий авто, которому нужно сохранять записи о произведенных махинациях с машиной.

## ***Краткое описание***
В данном проекте есть 3 главных сущности:
 - CarData - entity, содержащая информацию о машине, а также о ее владельце.
 - MechanicData - entity, содержащая информацию о механике, проводящем ремонтные действия.
 - RepairData - entity, содержащая в себе информацию о проведенных над машиной работах. Включает в себя вложенные сущности: CarData и MechanicData, а также общую сумму ремонта.
